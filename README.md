#Machine Learning Based Recommendation System for E-commerce Platform
A dynamic recommendation system combining Collaborative Filtering and Content-Based Filtering with adaptive weighting.

#Feature
1. Collaborative Filtering (user similarity using cosine similarity)
2. Content-Based Filtering (product feature similarity)
3. Dynamic Hybrid Model

#Adjusts weights based on user activity
1. Cold-Start Handling (popularity-based recommendations)
2. Evaluation Metrics
3. Precision, Recall, NDCG, F1 Score

#Tech Stack
1. Python
2. Pandas, NumPy
3. Scikit-learn
